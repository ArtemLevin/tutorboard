# Создание учебных 3D-сценариев

Сценарии объявлены в `src/core/solid-3d-learning/scenarios.ts` и закреплены
версией. Открытая попытка хранит `scenarioId` и `scenarioVersion`, поэтому
изменение каталога не меняет критерии уже начатого занятия.

Обязательные поля:

- устойчивый `id` и новая `version` при изменении критериев;
- цель, сложность, ожидаемое время и тренируемый навык;
- поддерживаемые виды тел;
- три semantic anchor для многогранника;
- вопросы прогноза;
- трёхуровневая лестница помощи;
- минимум два итоговых вопроса;
- вычислительные задания с явными единицами и tolerance, если они нужны.

Проверка сценария:

```bash
npx vitest run tests/unit/core/solid-3d-learning.test.ts
```

Перед выпуском добавьте golden fixture для всех фаз, browser smoke и проверьте
два направления обхода контура. Формулировки diagnostics должны описывать
причину и ближайшее полезное действие ученика.
