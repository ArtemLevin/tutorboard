# ADR-031: Учебный слой поверх semantic 3D

**Статус:** принято  
**Дата:** 2026-08-08

## Контекст

Свободный 3D-редактор вычисляет сечение сразу после выбора трёх точек. Для
обучения стереометрии требуется наблюдаемый цикл: прогноз, построение по
граням, обоснование, вычисление и закрепление. Состояние ученика должно
переживать перезагрузку и воспроизводиться при совместном просмотре.

## Решение

- `core/solid-3d` остаётся геометрическим источником истины.
- `core/solid-3d-learning` содержит детерминированные сценарии, попытку,
  валидаторы, точные значения, proof rules и аналитику без React, DOM и Three.js.
- `BoardDocument 1.4` хранит `solidLearningAttempts` отдельно от моделей тела.
- Команды `core.solid-3d-learning.*` используют `expectedRevision`.
- Камера, hover, вкладка, ghost-overlay и промежуточный drag остаются локальными.
- Drag записывает одну команду в контрольной позиции.
- Аналитический экспорт содержит учебные агрегаты, исключая содержимое доски.

## Последствия

Старые документы мигрируют добавлением пустого словаря. Reader сервера должен
принять документ, snapshot и ordered envelope `1.4` до production-включения
`VITE_FEATURE_SOLID_3D_LEARNING`.
