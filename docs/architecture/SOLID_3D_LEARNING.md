# Учебный режим 3D

## Пользовательский цикл

1. Учитель выбирает один из десяти сценариев и режим занятия.
2. Сценарий детерминированно размещает исходные точки.
3. Ученик прогнозирует число вершин, вид многоугольника и пересекаемые рёбра.
4. После отправки прогноза становятся доступны связанные 3D/2D-представления.
5. Ученик строит следы по граням; валидатор принимает оба направления обхода.
6. Ошибка получает стабильный diagnostic code и лестницу из трёх подсказок.
7. Ученик выбирает основания доказательства, формулу и точный ответ.
8. Мини-квиз и итоговая карточка завершают попытку.
9. Учитель воспроизводит trace и экспортирует обезличенные JSON/CSV-агрегаты.

## Модули

| Слой | Ответственность |
| --- | --- |
| `core/solid-3d-learning/types.ts` | Версионируемая попытка и действия |
| `attempt.ts` | State machine, лимиты, результат |
| `projection.ts` | Изометрия, виды спереди/сверху/сбоку |
| `prediction.ts` | Нормализация и оценка прогноза |
| `construction.ts` | Граф следов, цикл, диагностика, подсказки |
| `exact-values.ts` | Целые, дроби, десятичные и простые радикалы |
| `proof.ts` | Правила, предпосылки и русский текст решения |
| `dynamics.ts` | Anchored drag, выборка площади и критические положения |
| `scenarios.ts` | Каталог из десяти версионированных заданий |
| `analytics.ts` | Локальные метрики, JSON и CSV |

## Сохранение и совместная работа

Синхронизируются prediction, accepted/rejected steps, hints, diagnostics,
reasoning, answers, checkpoints, quiz и result. Каждая мутация увеличивает
`revision`. Trace ограничен 128 действиями, подсказки — 24, diagnostics — 64.
Удаление semantic solid каскадно удаляет его попытки. Clipboard тела не копирует
историю другого ученика.

## Производственные ограничения

- учебный интерфейс остаётся в lazy 3D chunk;
- idle viewport рендерится по событиям;
- расчёт drag выполняется по кадрам, commit создаётся при завершении;
- WebGL fallback сохраняет каталог, формы, список элементов и 2D-проекции;
- reduced motion отключает переходы;
- `VITE_FEATURE_SOLID_3D_LEARNING` подчинён `VITE_FEATURE_SOLID_3D`;
- rollback выполняется выключением учебного флага без потери reader compatibility.
